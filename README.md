## ✨ Tính Năng Nổi Bật

- 🎨 **Giao diện hiện đại & lãng mạn**: Thiết kế thẩm mỹ cao, tôn vinh từng khoảnh khắc ngọt ngào của các cặp đôi.
- 📸 **Thư viện Album Cưới**: Trưng bày các bộ ảnh cưới pre-wedding, phóng sự cưới theo phong cách điện ảnh, Hàn Quốc, vintage...
- 👗 **Bộ sưu tập Trang Phục**: Khám phá các mẫu váy cưới công chúa, đuôi cá, áo dài truyền thống và vest chú rể sang trọng.
- 💰 **Bảng Giá & Dịch Vụ Minh Bạch**: Liệt kê chi tiết các gói chụp studio, ngoại cảnh, ngày cưới.
- 📱 **Tương thích toàn diện (Responsive)**: Trải nghiệm mượt mà trên cả máy tính bàn, máy tính bảng và điện thoại di động.
- ⚡ **Tối ưu SEO & Hiệu năng cao**: Tận dụng sức mạnh của Next.js App Router, SSR, tối ưu hóa tải ảnh và font.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Môi Trường Local

### Yêu Cầu Hệ Thống
- [Node.js](https://nodejs.org/) phiên bản 18.18+ trở lên
- npm, yarn, pnpm hoặc bun

### Các Bước Thực Hiện

1. **Clone repository**:
   ```bash
   git clone https://github.com/xuancanh04/TUANTU-WEDDING.git
   cd TUANTU-WEDDING
   ```

2. **Cài đặt thư viện phụ thuộc**:
   ```bash
   npm install
   ```

3. **Khởi chạy máy chủ phát triển**:
   ```bash
   npm run dev
   ```

4. **Mở trình duyệt** và truy cập:
   ```text
   http://localhost:3000
   ```
